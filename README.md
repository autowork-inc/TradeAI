## Overview
TradeAI is an asynchronous, multi-strategy algorithmic trading platform and live execution engine designed for digital assets and market instruments. Built with Python 3.12, Polars, FastAPI, and PostgreSQL 16, it operates in both zero-capital Shadow Mode (vectorized execution and forward-testing on public WebSocket streams) and Live Mode using deterministic risk management protocols. All pattern math, market structure logic, and feature engineering are processed using pure, causal vector operations in Polars, avoiding loop-based state calculations or lookahead bias.

## Key Features
The core system is orchestrated around a Multi-Strategy Execution Engine capable of evaluating parallel trading setups (including SMC Swing, Counter-Trend, OBI Breakout, ICT Killzones, and Anchored VWAP Reversion) on 15m and 1h intervals. Trade entries are evaluated against Higher Timeframe (H4) market structure constraints and isolated per symbol-strategy key to prevent cross-strategy position interference. Risk management is strictly deterministic: positions are sized against fixed loss limits, constrained by strict daily drawdown caps, and backed by automated Scale Out logic (partial profit taking, breakeven stop-loss adjustments, and ATR-based dynamic trailing stops). The platform includes a PostgreSQL persistent layer logging every trade event and market snapshot, an internal FastAPI monitoring server with row-level read-only safety, an interactive desktop client built with Flet and Lightweight Charts, and a dedicated MCP (Model Context Protocol) analytical server designed to interface with AI risk management tools via read-only database tools.
