# TradeAI Monitor — настольный клиент (Этап 6)

Окно на вашем ПК с Windows: живое состояние Shadow Mode, статистика и история сделок с графиком каждой сделки.
Работает через API на сервере (`api/`, сервис `api` в `docker-compose.yml`). **Папка `client/` на сервер не отправляется**
(`scripts/deploy_pack.py` её исключает, тест `tests/test_deploy.py` это проверяет).

| Вкладка | Что показывает | Откуда |
|---|---|---|
| **Dashboard** | карточка на монету: состояние автомата SMC (S0…S4) отдельно для шорта и лонга, открытые заявки/позиции, лента событий, «пульс» Shadow | WebSocket `/ws/live_state` (обновляется само) |
| **Statistics** | Win Rate, Profit Factor, Net R, средний R ± ошибка, макс. просадка, **рейтинг монет по Net R** (лучшая отмечена), кривая накопленного R, разбивки по стратегиям/сторонам/причинам выхода | `GET /api/stats` (фильтры: монета, стратегия, сторона, период) |
| **Favorites** | эталонные сетапы (звёздочка в History или на графике), общие для профилей SANTA и CHR; сервер сохраняет их в `golden_set` для будущих примеров ИИ | `GET /api/trades?favorite=true`, `PUT/DELETE /api/favorites/{id}` |
| **History** | таблица сделок с фильтрами и страницами; **двойной клик по строке** (или кнопка справа) открывает окно графика | `GET /api/trades`, `GET /api/trades/{id}/snapshot` |

> Пока закрыто меньше ~200 сделок, вкладка Statistics честно предупреждает: знак Net R статистически не отличим от нуля,
> выводов о прибыльности делать нельзя (правило проекта, CLAUDE.md разд. 0 и 3.11).

## 0. Профили и обновления (с версии 0.2.0)

* **Пользователь** (кнопка в шапке): SANTA — всё как раньше; CHR — только стратегии `Trendline/Horizontal Breakout (CHR)`, свой пул монет (EUR, GBP, JPY, XAU, BTC, ETH + «Монеты CHR…» в настройках) и баланс, который всегда стартует с 0$ и растёт/падает только от сделок CHR. Выбор запоминается.
* **Автообновление:** при старте клиент сверяет версию с `version.json` на сервере; если там новее — предложит обновиться (скачает .exe, проверит контрольную сумму, перезапустится). Выкладка новой версии: `powershell -File build_exe.ps1 -Publish -Version 0.3.0 -Notes "что нового"` (нужен SSH-ключ к серверу).
* **Монеты** в фильтрах — выпадающий список с чекбоксами («Выделить всё / Снять всё»), результат обновляется сразу по клику.

**Версии (с 1.0).** История изменений — `tradeai_client/changelog.json`. После обновления при первом запуске показывается окно «Приложение обновлено до версии X.X» со списком изменений этой версии; полная история — в настройках, кнопка «История обновлений». Выпуск новой версии: добавьте запись в начало `changelog.json`, затем `powershell -File build_exe.ps1 -Publish -Version 1.1` (без записи сборка остановится; на сервер уходит .exe и `version.json` с историей).

## 1. Подключение к серверу

API на сервере опубликован на **`0.0.0.0:8001`** (порт 8000 на сервере занят другой программой; внутри контейнера API слушает 8000).
SSH-туннель не нужен: адрес по умолчанию зашит в сборку — `http://193.233.75.254:8001` (`tradeai_client/build_defaults.py`).
Порт 8001 должен быть открыт в файрволе сервера (например `ufw allow 8001/tcp`) и у провайдера.

Ключ на сервере: `./deploy/shadow.sh apikey`.

**Запуск в один клик.** Положите `TradeAI-Monitor.exe` в любую папку и запустите:

* нет файла `settings.json` рядом с `.exe`, но в сборку зашит ключ → приложение сразу подключается;
* нет файла и ключа в сборке нет → откроется окно настроек; после «Проверить и сохранить» адрес и ключ записываются в
  **`settings.json` рядом с `.exe`**, и при всех следующих запусках подтягиваются автоматически (окно настроек не открывается);
* если рядом с `.exe` писать нельзя (например, `Program Files`), приложение покажет ошибку сохранения: положите `.exe` в папку с правом записи. Старый `%APPDATA%\TradeAI Monitor\settings.json` (от версии с туннелем) больше **не читается**;
* переменные окружения `TRADEAI_API_URL` / `TRADEAI_API_KEY` сильнее файла. Перенести настройки на другой ПК — скопировать `settings.json`.

> ⚠ Это обычный HTTP: ключ `X-API-Key` идёт по сети открытым текстом (клиент показывает предупреждение). Защита — только ключ и
> троттлинг перебора на сервере (10 неверных ключей за 60 с → блокировка адреса на минуту). Вернуть доступ «только с сервера»
> (через SSH-туннель): `API_BIND=127.0.0.1` в `.env.shadow` на сервере, затем `ssh -N -L 8000:127.0.0.1:8001 user@сервер` и адрес
> `http://127.0.0.1:8000` в клиенте. Ключ, зашитый в `.exe`, читается любым, у кого есть файл; `settings.json` тоже хранит ключ
> открытым текстом — не выкладывайте папку с `.exe` в облако и не передавайте её посторонним.

## 2. График сделки

Двойной клик по сделке (или кнопка в строке) открывает **отдельное окно** с интерактивным графиком на **TradingView Lightweight Charts 4.1** (WebView2; файлы страницы лежат в `tradeai_client/chart_web`):

* **Реальное время.** Крипта: история и поиск по REST Binance Futures, текущая свеча обновляется WebSocket'ом `kline` (резервный опрос раз в 3 с, если поток молчит; статус `LIVE · время` в шапке). Forex/металлы (MT5): свечи отдаёт API сервера (`/api/candles`, кэш бота из MetaApi: закрытые M5 и формирующаяся свеча по котировкам раз в секунду; нужен сервер версии от 2026-10-19).
* **Таймфреймы и история.** Кнопки 5m / 15m / 1h / 4h; время просмотра при переключении сохраняется. Прокрутка влево подгружает историю страницами по 1000 свечей, сколько есть у источника.
* **Рисование** (панель слева): линия, горизонтальная линия, луч, область (прямоугольник с заливкой). Цвет, толщина, прозрачность; курсор `↖` выбирает рисунок (можно тянуть за тело и за маркеры), `Delete` / `🗑` удаляет, `✕` (два раза) очищает монету, `Esc` отменяет. **Рисунки сохраняются** в `drawings.json` рядом с `.exe` по тикеру (время + цена, поэтому они остаются на месте при смене таймфрейма) и подгружаются при следующем открытии монеты.
* **Логика бота (стратегии CHR).** Поверх свечей рисуется то, что увидел бот: уровень или наклонная линия, точки касания, точки поджатия и линия между ними, пробойная свеча, стоп; справа - карточка «Что увидел бот». Касания и точки поджатия клиент восстанавливает по свечам снапшота тем же правилом, что детекторы бота, и **сверяет** с `meta` (число касаний, цены поджатия): результат («совпадают» / «НЕ совпали») показан в карточке. Кнопка «Логика бота» включает и выключает слой.
* Остальное, что было: маркеры входа и закрытий, линии SL / TP / вход, зона FVG, справа панель «Результат / Разбор сделки / Хронология / Причина входа», звёздочка «Избранное».

Время на осях и в перекрестии - в поясе вашего ПК. Каждое окно графика - отдельный процесс; при закрытии приложения они закрываются вместе с ним. Живая проверка окна (в т.ч. собранного `.exe`): `TradeAI-Monitor.exe --selftest-chart снимок.png`.

## 3. Запуск из исходников

```powershell
cd client
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe app.py
```

Нужны Python 3.12 и **Microsoft Edge WebView2 Runtime** (в Windows 11 есть; в Windows 10 при отсутствии окно графика не откроется —
установите «Evergreen Runtime» с сайта Microsoft). Версии библиотек зафиксированы: Flet 1.x меняет API между минорными версиями,
а lightweight-charts 2.1 **не работает с pandas 3** (ось времени превращается в 1970 год и свечи не рисуются) — поэтому `pandas<3`.

Просмотр интерфейса в браузере при разработке: `flet run --web app.py` (окна графиков всё равно откроются отдельно).

## 4. Сборка в .exe (`flet pack`)

Автоматически (создаст `.venv`, поставит зависимости, прогонит тесты, соберёт):

```powershell
cd client
powershell -ExecutionPolicy Bypass -File build_exe.ps1            # один файл dist\TradeAI-Monitor.exe; адрес из build_defaults.py, ключ вводится при первом запуске
powershell -ExecutionPolicy Bypass -File build_exe.ps1 -ApiKey <ключ с сервера>   # ключ зашит в .exe: запуск в один клик без ввода
powershell -ExecutionPolicy Bypass -File build_exe.ps1 -ServerUrl http://host:8001 -ApiKey <ключ>   # другой адрес
powershell -ExecutionPolicy Bypass -File build_exe.ps1 -OneDir    # папка dist\TradeAI-Monitor\ (запускается быстрее)
```

`-ServerUrl` / `-ApiKey` (или переменная `TRADEAI_BUILD_API_KEY`) подставляются в `tradeai_client/build_defaults.py` только на время
сборки, после неё файл возвращается в исходный вид (ключ в репозитории не остаётся).

Вручную — то же самое одной командой (из каталога `client`, при активном `.venv`):

```powershell
flet pack app.py --name TradeAI-Monitor --product-name "TradeAI Monitor" --product-version 0.1.0 --distpath dist -y "--pyinstaller-build-args=--collect-all=lightweight_charts"
```

* `--collect-all=lightweight_charts` обязателен: js/css/html окна графика PyInstaller сам не находит;
* в `app.py` первой строкой вызывается `multiprocessing.freeze_support()` — без этого каждое окно графика в .exe запускало бы ещё одну копию приложения;
* сборка занимает несколько минут; размер файла — десятки МБ (внутри Flutter-клиент Flet, Python, pandas/numpy);
* неподписанные PyInstaller-программы иногда ругает антивирус (ложное срабатывание); `-OneDir` ругается реже. Подпись кода — отдельная задача.

## 5. Тесты

```powershell
cd client
.\.venv\Scripts\python.exe -m pytest tests -q -W ignore::DeprecationWarning
```

Тесты не требуют сервера: ответы API взяты из `tests/fixtures/*.json` (снимки настоящих ответов `api/`; тест
`tests/api/test_api_db.py::test_client_fixtures_match_the_api_contract` в корневом проекте сверяет их ключи с живым API, поэтому разъезд
контракта не пройдёт незамеченным). Чтобы обновить фикстуры: поднять демо-API (`scripts/demo_api_data.py`, см. CLAUDE.md разд. 3.19) и снять ответы.

## 6. Если что-то не работает

| Симптом | Причина / что делать |
|---|---|
| «Сервер недоступен» | порт 8001 закрыт файрволом, контейнер `api` не запущен (`./deploy/shadow.sh status`) или неверный адрес; проверьте `curl http://193.233.75.254:8001/api/health` → `{"status":"ok"}` |
| «Неверный API-ключ» | ключ из `./deploy/shadow.sh apikey`; после 10 неверных попыток сервер блокирует вход на минуту (429) |
| Dashboard: «Shadow НЕ отвечает» | пульс `shadow-run` старше 2 минут: смотрите `./deploy/shadow.sh status` / `logs` |
| Dashboard: «Сервер не может прочитать базу» | `postgres` недоступен: `./deploy/shadow.sh logs api` |
| Окно графика пустое/не открывается | нет WebView2 Runtime (Windows 10); либо pandas 3 в окружении (`pip install "pandas<3"`) |
| На графике нет свечей после сигнала | Binance недоступен с вашего ПК (причина — в панели «Результат»); отключите опцию в настройках, чтобы не ждать таймаута |
| Двойной клик не срабатывает | нажмите кнопку-свечу в конце строки (то же действие) |
